# Stats cards that feel native to GitHub

## Five inspectable references

1. [Pedro Catalao's live profile](https://github.com/pedrocatalao) — user's preferred reference for stats cards integrated into GitHub-like surfaces.
2. [Pedro's `github-cool-readme` repository](https://github.com/pedrocatalao/github-cool-readme) — inspect card examples and how the cards use GitHub-like visual tokens.
3. [Seiji Kohara's Profile Cards GitHub Action](https://github.com/marketplace/actions/profile-cards) — example gallery with Primer colors, light/dark variants, small stat tiles, and varied contribution views.
4. [GitHub Profile Stats by shinpr](https://github.com/shinpr/github-profile-stats) — compact/wide variants, light/dark output, and three distinct data presentations.
5. [Rowkavdev GitHub Profile Stats](https://github.com/rowkavdev/GitHub-profile-stats) — compare GitHub, minimal, compact, split, and editorial card layouts.

## Five ideas to adapt

1. **Use one shared card system.** Keep a single surface color, thin border, subdued labels, and one accent green/cyan across each metric; avoid different services' default card skins.
2. **Prefer a wide activity summary over several boxes.** Show contributions, current streak, and longest streak together in one calm card, with the calendar or sparkline doing most of the visual work.
3. **Let the GitHub theme set the palette.** Use paired light/dark images or a theme-aware SVG so the design follows the viewer's GitHub appearance.
4. **Keep numbers subordinate to labels and context.** For example, use a compact `184 contributions · 9 day streak · 82 day best` line with a small graph; skip trophy/rank framing and excessive iconography.
5. **Keep a single card as supporting evidence.** Give the top of the profile to the name and project proof; place the stats panel below or beside a short “activity” heading so it does not become the main event.

## Checks and limits

Links resolve to GitHub repositories/profile pages or the GitHub Marketplace. Source descriptions and examples were checked through web search/open results. I did not render every SVG in a browser, so appearance may vary with GitHub's image proxy, theme selection, or current project implementation. The five ideas are design recommendations inferred from these examples, not claims from the project authors.
